# JADEX HQ

**Executive Admin Dashboard** — A modern analytics and operations command center built from scratch with HTML, CSS, and JavaScript to track performance across the entire Jadex ecosystem.

## About the Project
Jadex HQ unifies key metrics, revenue visualizations, and live transaction records across **Jadex Rocks**, **Jadex Voyages**, **Maison Jadex**, **Jadex Films**, and **Jadex Academy**.

## Design & Aesthetic
* **Hybrid Executive Palette:** Pairs a Sleek Slate Dark sidebar with a Crisp Cloud White workspace, illuminated by Royal Indigo, Electric Violet, and Mint Emerald accents.
* **Pure CSS Charts:** Features a responsive monthly bar chart and a custom `conic-gradient` brand-share donut chart with zero third-party chart libraries.

## Features
* **Dynamic Timeframe Switcher:** Toggling between *This Month*, *Last Quarter*, and *Full Year 2026* smoothly animates bar chart heights and updates all four KPI cards in real time.
* **Live Table Search Filter:** Instantly filters customer orders by client name, order ID, item, or Jadex brand as you type.
* **Responsive Sidebar Shell:** Adapts seamlessly from a two-column desktop command center to a compact mobile header.

## Built With
* **HTML5** — Semantic dashboard grid, data tables
* **CSS3** — Custom variables, CSS Grid, Flexbox, `conic-gradient` charts, and smooth height transitions
* **Vanilla JavaScript** — Live dataset switching and real-time table filtering
